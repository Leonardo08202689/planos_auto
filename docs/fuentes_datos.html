Fuentes de Datos SIG

De dónde viene cada capa que Planos Auto dibuja. Ante cualquier duda —propia, de un colega o de una autoridad— sobre qué dataset oficial respalda un plano, esta es la referencia.

Cada capa vive en PostGIS (esquema proyectos u otros) y se referencia en config/proyectos/*.json mediante el campo "fuente". Si se actualiza un dataset —por ejemplo, INEGI publica una nueva serie— hay que actualizar el JSON y esta página juntos.

Cómo leer la escala: 1:50 000 → mayor detalle 1:1 000 000 → menor detalle

Notas

  1. El campo "fuente" de cada capa en config/proyectos/*.json es la referencia oficial: si un dataset se actualiza, el JSON y esta página se actualizan juntos para no desincronizarse.
  2. La escala indica la resolución del levantamiento oficial: a mayor número en el denominador, menor detalle; a menor número, mayor detalle.
  3. Ante cualquier duda sobre vigencia, verificar directamente en INEGI, CONABIO, CONANP o SEMARNAT según corresponda.
